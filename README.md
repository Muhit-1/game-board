# Game Board

A simple site my cousins and I made for our game nights. We kept ending up making our own board by hand out of paper (and whatever else was lying around) every time we wanted to play Catan, so we built this instead — a shared digital board anyone can use.

## What's here

| Game | What it does |
|---|---|
| **Catan** | A shared on-screen board and scoreboard for a physical Catan game night. You still use real cards and dice — this just draws the board, lets everyone place their pieces, and keeps score automatically where it can. |

More boards might get added here later if we make them.

## How to use it

Open the hub page, pick a game, choose how many people are playing, and start. No installs, no accounts — it just runs in the browser.
